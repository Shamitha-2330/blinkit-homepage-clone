# Blinkit Home Page (Recreation)

A static front-end recreation of the Blinkit home page, built with HTML and CSS to practise layout structure, spacing and component styling.

> Recreation built for learning and practice.

## Screenshot

![Blinkit home page](Images/website_scrnshot.png)

## About

This project recreates the Blinkit home page as a desktop layout. It focuses on page structure and visual styling only. There is no cart, search or backend functionality.

## Tech Stack

- HTML5
- CSS3

## What I Practised

- Breaking a real-world page design into sections and reusable components
- Building grid-style layouts for categories and product sections with Flexbox and CSS Grid
- Spacing, alignment and typography consistency
- Styling buttons, cards, headers and footers

## How to Run

1. Clone the repository
   ```bash
   git clone https://github.com/Shamitha-2330/blinkit-homepage.git
   ```
2. Open `index.html` in any browser, or use the Live Server extension in VS Code.

## Known Limitations

- Desktop layout only; not yet responsive for tablet and mobile
- Static page with no interactive features

## Planned Improvements
